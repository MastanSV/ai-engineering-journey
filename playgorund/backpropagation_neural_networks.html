The problem
A weight changes the loss indirectly.

A weight doesn't reach into the loss and say “change.” It changes a value next to it. That value changes another value, and eventually the prediction changes. The loss notices the prediction.

Backpropagation is our way of tracing that chain backward.

The useful mental model
Follow the dependency path backward, and multiply the local effects as you go.

You don't need to memorize a giant formula. At each arrow, ask: “If this value moves a tiny bit, how much does the next value move?”

Why the chain rule fits perfectly

Imagine A affects B by ×2. B affects C by ×3. C affects D by ×4. A tiny change in A therefore has an overall effect of:

2 × 3 × 4 = 24

That is the chain rule. A neural network is just a much bigger chain — usually with branches — and backpropagation applies this idea efficiently.

Gradient sign

Gradient descent

Move opposite the gradient because we want the loss to go down.

The one-line explanation

“Gradient coming in × local derivative = gradient going backward.”
